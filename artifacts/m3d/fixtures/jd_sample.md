## 岗位职责

1. 负责 AI Agent 应用的架构设计与开发，落地工具调用、多步规划与记忆机制；
2. 基于 RAG 构建检索增强问答链路，完成向量检索与召回效果优化；
3. 与产品、算法协作，完成 Prompt 设计与效果评估，输出可复现的实验记录；
4. 参与服务端接口开发与部署，保障线上稳定性。

## 任职要求

- 熟悉 Python，具备 FastAPI 或 Spring Boot 之一的服务端开发经验；
- 熟悉 LLM 应用开发，了解 LangChain / LlamaIndex 等框架；
- 掌握向量数据库（ChromaDB、Milvus、FAISS 任一）与向量检索原理；
- 具备 Docker 与 CI/CD 实践经验，熟悉 Linux 环境；
- 了解 TypeScript 与 React 者优先；
- 有 MCP、gRPC 协议实践经验者优先；
- 具备良好的沟通能力与工程习惯，能独立排查线上问题。

## 加分项

- 有 Kubernetes 部署与监控经验；
- 有微调（fine-tuning）或 Prompt 工程体系化建设经验；
- 有知识图谱或 GraphQL 相关实践经验。
