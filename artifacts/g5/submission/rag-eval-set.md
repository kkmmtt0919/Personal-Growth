# 检索评测集（10 条样本与判定标准）

> 受控构造的提交样例（`growth_constructed=true`，如实标注）：用于 M5-c 真实运行验证
> 「提交 → 单入口证据 → 材料 claim → 绑定 → 重评 → 归因」闭环；不代表用户本人的真实产出。

## 判定标准

- 命中：Top-3 结果包含期望文档的对应段落；
- 部分命中：Top-5 包含但 Top-3 不包含；
- 未命中：Top-5 均不包含。
