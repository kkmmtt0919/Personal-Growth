# O3 新目标任务与证据闭环（2026-10-07）

首次使用服务现在同时提供目标澄清、能力树、缺口任务生成、任务操作、回答与文件提交、证据读取及重评归因。用户选择第三层能力点与理解/实践维度后，先经既有评定编排建立可追溯缺口，再由TaskGenerator与七步闸门创建任务。没有证据显示证据不足，不判断能力低。重复请求复用未结束任务。

默认固定结构/任务模板、按任务来源的固定绑定规则；不判断回答与产物质量。真实模型仍须显式配置，本轮零真实模型请求。任务提交只经过TaskLoop既有链路与持久请求账本；目标生成和任务提交共用互斥锁。地址栏保留实际目标ID，任务、证据和返回能力树链接均沿该目标。
