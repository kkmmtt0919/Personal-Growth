# O1 · 目标澄清与显式确认入口

2026-10-06。独立首次使用实验库，通过既有GoalAgent状态机保存目标、四要素问答与确认原话。默认固定问句，回答逐字段保存原话；不宣称模型理解或真实模型澄清效果。能力树生成尚未接入。

## 已实现

- `/start`输入目标、四要素问答、待确认提议、确认原话与显式确认；保存目标列表支持刷新后继续。
- 重复创建请求返回原会话，同轮同回答不重复发模型，不同回答拒绝覆盖历史；确认重放幂等。
- 未就绪不能确认，确认不是模型请求。最多六轮，达到上限后不再发模型。
- 提问失败保存目标、已答内容与失败运行记录；独立resume入口仅在无待答问题时显式恢复，不自动重试。
- 原Demo、交互实验库保持隔离；新实验仅使用onboarding.db，不写材料或评级。单进程服务锁复用请求账本的锁机制，未写任务提交记录。

## 验证

33项接口与既有澄清状态机定向测试、484项完整回归通过，见regression.xml。14项真实浏览器检查通过，含中途刷新恢复、明确待确认、不自动确认、原话保留、确认结果刷新可读及1440/390px无溢出。ruff与前端build/lint通过。截图、browser-verification.json为受控浏览器场景，零真实模型调用。

`GROWTH_ONBOARDING_REAL_MODEL=1`可在启动前显式接现有网关；本轮未执行该模式，也不续期历史G1真实模型验收。能力模型生成、地图联动、实时模型验收和完整MVP继续留后续。
