# Growth OS 前端改版验证

首页采用暖白底、近黑文字、朱红选中状态和细分隔线；中央能力地图由真实接口数据生成，点击能力联动右侧等级与缺口。证据页与任务页使用相同视觉体系。

## 数据与兼容

- 保留现有三个页面路由和后端接口。关联任务通过任务 ID 锚点定位。
- 地图任务连线使用现有缺口的 dimension 字段，已完成的实践任务不会被画成补齐当前理解缺口的任务。
- 示例库只有一项能力；实际截图只显示该项，不补造效果图中的额外能力。
- 返回摘要的来源、证据引用和重评归因检查均可展开核对。
- 本地默认 API 地址明确为 127.0.0.1:8000，与启动说明一致；VITE_API_BASE_URL 仍可覆盖。首页依次读取目标、能力、返回摘要、任务。

## 验证结果

前端 build、lint 和 git diff --check 通过。真实 Edge 浏览器检查 53 项通过，无 JavaScript 运行时错误。

- 1440、1024、390px 下的首页、证据页和任务页均无横向溢出。
- 基础 Demo 与返回 Demo 均验证；三种宽度下检查证据跳转及任务锚点／焦点定位。
- 响应夹具检查多能力切换、键盘 Enter 操作、选择时保留滚动位置、未评估与无关联任务。
- 检查下一步的推荐任务优先级、未完成任务回退、无任务时定位能力详情。
- 检查空能力、空任务、空证据、加载、接口失败、重新加载恢复及减少动态效果设置。
- 多能力和边界场景使用临时浏览器响应夹具，未修改数据库。

验证脚本：scripts/verify_frontend_redesign.cjs。重跑需要前端 :4173、返回 Demo :8000、基础 Demo :8001，以及独立 headless Edge DevTools :9228。
