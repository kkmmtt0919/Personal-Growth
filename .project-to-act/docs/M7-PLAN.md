# M7 主动 Agent 边界（v0.1 · 待确认）

M7 只做确定性事件检测和通知抑制，不做持续学习、自动修正或导师人格。

## 检测

每日分析由可注入时钟驱动，默认每天最多一次。四类事件：

| 事件 | 条件 | 动作 |
|---|---|---|
| `capability_evidence` | 新 assessment 的等级高于前一条 | 通知 |
| `practice_stalled` | 窗口内理解证据增加且实践任务完成为 0 | 行动建议 |
| `gap_without_task` | open gap 且等级差 ≥2，窗口内无任务 | 调用现有任务生成链 |
| `goal_changed` | confirmed goal 的来源陈述发生变化 | 标记需要重新生成能力模型，不在分析中直接生成 |

无事件则不写通知。

## 抑制

- 每类事件有冷却期，默认 7 天。
- `g_notifications` 记录事件、通道和关闭状态。
- 用户关闭主动提醒后，检测可以运行，但不得新增通知。
- 事件继续写入现有 `g_events`，新增 kind 只限这四类。

## M7-b 调度边界（2026-10-04 已确认并完成）

- 进程内调度器只负责按可注入时钟调用 `run_daily`，默认每天一次。
- 同一用户同一自然日重复触发时直接返回上一次结果，不重复检测。
- 分析异常写入一条错误事件后停止，不自动重试。
- 通知只写 `g_notifications`，不接邮件、推送或 UI。
- 目标变化仍只记录再生请求，不在调度中生成能力模型。

## 不做

自动学习、记忆权重、遗忘、冲突合并、Mentor 对话、UI 和目标变化后的立即重生成。目标变化只产生明确的再生请求，实际生成留在后续确认步骤。
