## G6-a · 只读返回契约

输入：明确的 user/goal、已持久化的基线快照和当前快照、可注入返回时间。

输出：

- 变化摘要：理解/实践分别比较，引用前后 snapshot 与 assessment 标识；无基线明确说无法比较，未知或跨用户快照拒绝。
- 当前状态：只从已确认目标、active capability、open gap 与已有任务读取；不由任务完成状态推断星级。
- 下一步：引用当前 open gap 或 active/proposed task；无任务时只说明缺哪类证据，不自动生成任务、不给排序分数。
- 长期偏好：只引用 active profile memory 的内容与 source_kind/source_id；无偏好明确说未记录，不编造。

只读调用不能写 memory、snapshot、assessment、task 或通知。输出如使用确定性模板，应如实标注；不能据此宣称验证了真实模型的导师推理。

关键反例：无基线、无变化、评级不足（NULL）、不同维度、目标/快照不匹配、没有偏好、任务 done 但评定不变、当前快照过时。

## G6-b · 隔天持久化场景与补证

在独立实验库记录长期偏好与前快照，经过现有任务闭环生成新评定和后快照。
关闭存储连接，再重新打开，注入次日时间，调用 G6-a。记录完整输出、snapshot diff、来源和页面截图。

截图应能同时看到变化、下一步和偏好引用；不是只拍一个“3 → 4”数字。受控材料与时间模拟须标注。
